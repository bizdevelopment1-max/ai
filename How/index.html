LONG-RUN CASES

실제 본 사이트에서 반복된 문제를 원인 · 해결 · 재발 방지로 정리

CASE 01 · DUPLICATION

같은 기업과 같은 기사가 여러 곳에 반복

문제소스마다 기업 표기와 기사 제목이 달라 중복 카드가 누적

CASE 02 · ORGANIZATION

조직도 인물과 프로필이 실제 인물과 불일치

문제이름 검색 링크와 오래된 기사만으로 직책과 경력을 확정하기 어려움
해결공식 임원 페이지·공시·직접 프로필을 우선해 직책과 배경을 병합
방지검증된 직접 링크가 없는 경우 링크를 만들지 않고 공개에서 제외
PROOF · official-only leadership validation
CASE 03 · LOAD SPEED

기업·뉴스·주가 데이터를 한 번에 불러 로딩 지연

문제초기 화면에 필요하지 않은 상세 데이터까지 동시에 요청
해결화면이 가까워질 때 섹션별 데이터와 상세 정보를 지연 로딩
방지화면용 공개 뷰를 분리하고 번들·데이터·초기 렌더 계약을 검사
