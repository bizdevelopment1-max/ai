03
COLLECTION PIPELINE

검색 제목이 아니라 발행사 원문을 저장

수집량보다 출처 품질과 주제 적합도가 중요한 자동화 원칙

STEP 1질의시장·기업·과금별 검색식
STEP 2발견후보 URL과 발행일
STEP 3원문 열기발행사 페이지 본문
STEP 4근거 추출숫자 포함 문장과 주체
STEP 5분류시장·수익·전략 안정 키
STEP 6공개품질 통과 최신값만 반영
수집 기준공식·리서치 우선 → 제목과 본문에서 대상 일치 → 숫자 의미와 기간 확인 → 원문 URL 유지
실행 주기하루 여러 차례 자동 실행 · 실적 발표와 주요 발표 이후 새 원문 반영
DO NOT검색 결과 제목만 저장 · 숫자만 추출 · 회사 이름이 없는 기사를 기업 카드에 연결

ANTI-HALLUCINATION GATES

AI 요약보다 먼저 통과해야 하는 5개 품질 게이트

근거 없는 그럴듯한 문장을 화면에 올리지 않는 방어 구조

GATE 01원문 존재발행사 페이지 접근 · RSS 제목만 있는 후보 제외
GATE 02주체 일치기업명·제품명·사업 주체가 본문에 직접 등장
GATE 03숫자 완전성무엇의 숫자인지 · 단위 · 기준기간 · 전망기간 확인
GATE 04중복 제거동일 사건 재배포는 하나의 인사이트와 근거 묶음으로 병합
GATE 05공개 정책금지어·사용자 삭제·저품질 출처를 마지막 단계에서 재검사
STOP숫자 라벨 없음 · 날짜 없음 · 회사 직접 연관 없음 · 출처 페이지 확인 실패 → 공개 스냅샷 승격 거부
BEGINNER TIP요약 프롬프트보다 먼저 if 조건으로 실패 기준을 코드화하면 품질 개선 속도 상승
